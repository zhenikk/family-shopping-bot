# Хостинг сімейного Telegram-бота (29 вересня 2026)

Вимоги цього репозиторію: Linux VM з Docker Compose, вихідний HTTPS до Telegram, постійний диск для SQLite й фото, архітектура `arm64` або `amd64`, локальний `whisper.cpp` з багатомовною моделлю `base`. Бот працює через long polling, тому публічний HTTP-порт і домен не потрібні ([README](../README.md), [Dockerfile](../Dockerfile), [Compose](../compose.yaml)). Ціни нижче перевірені за офіційними сторінками, але кінцеву суму для резидента Португалії треба звірити у кошику до оплати.

## Висновок

**Основний вибір — netcup VPS nano G11.5s**: за підтвердженою ціною він вкладається в €5/міс із запасом і не має політики повернення idle VM. Це шестимісячне зобов'язання, а 2 ГБ RAM потребують перевірки. Рекомендований порядок: запустити Docker Compose, надіслати коротке голосове повідомлення, перевірити час відповіді й використання пам'яті під час `whisper base`. Якщо це не працює прийнятно, перейти на багатомовний `tiny` або сервер з 4 ГБ RAM; наявний Dockerfile не перемикає модель конфігурацією, тож для `tiny` треба змінити збірку. Перед купівлею перевірити остаточний кошик для Португалії.

**Безкоштовна альтернатива — Oracle A1**, якщо користувач погоджується з ризиком нестачі місткості та повернення неактивного інстансу. Обрати одну Ubuntu ARM64 VM з 2 OCPU і 4 ГБ RAM у межах безкоштовного ліміту. За будь-якого хостингу резервні копії SQLite/фото слід регулярно вивантажувати за межі VM. Не створювати штучне навантаження для обходу політики Oracle.
