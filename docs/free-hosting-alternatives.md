# Безкоштовний хостинг після нестачі місця в Oracle A1

Станом на 29 вересня 2026 року. Потреба: Telegram-бот для двох, доступний у будь-який час, зі спільною базою, фото й локальним розпізнаванням голосу. «Безкоштовний» означає постійну квоту після пробного періоду, а не тимчасові кредити. Квоти можуть змінитися. Google Cloud вимагає активний billing account навіть для Free Tier; безкоштовна квота не є жорстким лімітом витрат. Потрібно встановити бюджетні сповіщення й перевірити фактичні витрати після запуску. [Google Cloud Billing](https://docs.cloud.google.com/docs/get-started/learn-about-billing), [бюджети](https://docs.cloud.google.com/billing/docs/how-to/budgets)

## Практичне рішення

1. Якщо принципово **€0 надовго**, перенести бота на **Google Cloud Run + Firestore + Cloud Storage**, з Telegram webhook. Перед міграцією зробити proof of concept: одне реальне голосове, cold start, фото, оцінка трафіку й billing. Не обіцяти нульовий рахунок без виміру: квоти не обмежують автоматично всі платні SKU.
2. Якщо важливіше **запустити теперішній код швидко** і прийнятний бюджет до €5/міс, спробувати **Google `e2-micro`**; врахувати ~$3.60/міс за IPv4 та можливий платний вихідний трафік. Голос на 1 GB RAM та малому CPU може вимагати Tiny і все одно бути повільним. Це інженерний висновок із лімітів, не підтверджений тестом на конкретній VM.
3. За обох шляхів тримати резервну копію даних поза обчислювальним інстансом. Поточний бот із локальними SQLite й фото **не можна** просто розмістити на безкоштовному сервісі з тимчасовою файловою системою.
