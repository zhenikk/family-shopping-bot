# Сімейний бот покупок

## Закрита бета для друзів

Новий користувач відкриває `/start` і натискає «Створити сім’ю». Бот створює порожній сімейний список та надсилає приватне посилання для запрошення близьких. Кнопка «👥 Запросити до сім’ї» або `/invite` показує це посилання повторно. Друзі мають створювати власну сім’ю; ваше запрошення дає доступ саме до вашого списку. Посилання є секретом доступу: кожен його власник може приєднатися. Уже зареєстрований користувач не переходить до іншої сім’ї через випадкове запрошення.

Кожна нова сім’я має окрему SQLite-базу та папку фото в `data/families/<id>/`. `data/families.sqlite3` зберігає відповідність Telegram-користувачів сім’ям і секрети запрошшень. Початкові учасники, товари, фото та історія залишаються в наявній базі; `/join` зі старим кодом зберігає сумісність. Обмеження кількості учасників немає. Mini App, чат, чернетки, голосові й фонові сповіщення використовують базу поточної сім’ї.

Whisper обробляє один запис за раз двома CPU-потоками. Бот показує статус очікування та початку розпізнавання. Таймаут розпізнавання не встановлений; зависле або дуже довге завдання може затримати чергу. Щоденна резервна копія включає реєстр сімей, усі сімейні бази та фото. Копії на тому самому VPS не захищають від втрати сервера; початкова копія також збережена на ноутбуці.

Сервер: Ubuntu 24.04, Docker Compose у `/opt/family-shopping-bot`; `restart: unless-stopped`. Для оновлення: резервна копія → доставка перевіреного Git-коміту → `docker compose build bot` → `docker compose up -d bot`. Не запускайте другу копію polling-бота з тим самим Telegram-токеном. Поточний Quick Tunnel є тимчасовим; для постійної адреси потрібен власний домен і стабільний HTTPS.

Приватний Telegram-бот для двох людей. Кожен користується особистим чатом із ботом, а каталог товарів і список покупок спільні. Зараз бот можна запускати на Mac через Docker/OrbStack; пізніше той самий код можна перенести на віддалений Linux-сервер. Оновлення коду йдуть через GitHub. Немає відкритого порту для бота: він отримує повідомлення через Telegram long polling.

## Можливості першої версії

- Один спільний список за категоріями, доступний кнопкою «🛒 Список». Товари можуть мати необов’язкову постійну нотатку, наприклад «купити в Mercadona».
- Додавання списку текстом або голосом із підтвердженням одним натисканням. Підходять «молоко, яйця» та «сьогодні треба купити яйця, молоко і хліб». `картопля :: купити в Mercadona` додає нотатку; `хліб @Lidl` також працює як скорочення нотатки.
- Фото упаковки зберігається в каталозі. Надішліть його з назвою товару в підписі; кнопка 📷 відкриває фото зі списку.
- Куплений товар зникає зі списків обох людей. Другий учасник отримує одне повідомлення про похід по покупки; бот оновлює його після наступних покупок. Помилкову покупку можна скасувати.
- Історія з часом та ім'ям; магазин у старих записах зберігається. Куплений товар можна знову додати з каталогу.
- Голос розпізнається локально на вашому сервері через багатомовну модель `whisper.cpp small` із фіксованою українською мовою (`-l uk`), без автоматичного визначення мови. Жоден запис не надсилається в зовнішній AI API. Telegram доставляє голосові та фото через власні сервери.
- Дані зберігаються у SQLite й локальній папці фото на сервері. Окремий скрипт створює резервну копію.

Чеки, OCR, відстеження цін, облік запасів, кількості та автоматичні нагадування — наступні етапи. Для чеків планується локальний Tesseract, підтвердження знайдених рядків та історія цін за товаром і магазином.

## Локальний запуск на Mac

Потрібен запущений Docker Desktop або OrbStack. У корені репозиторію створіть `.env` із двома рядками: `TELEGRAM_BOT_TOKEN=` (токен від @BotFather) і `SHOPPING_INVITE_CODE=` (випадковий приватний код для двох учасників). Не додавайте `.env` до Git і не надсилайте токен у чат. Папка `data/` з SQLite та фото зберігається між перезапусками контейнера.

```bash
docker compose up -d --build
docker compose ps
docker compose logs --tail=50 bot
```

Для зупинки: `docker compose stop`; для повторного запуску: `docker compose start`. Поки Mac спить, вимкнений або Docker не працює, бот не отримує повідомлення. Після запуску кожен із двох учасників надсилає боту `/join ВАШ_КОД` у власному чаті.

## Чому згодом знадобиться віддалений сервер

Код живе в GitHub. Його можна змінити звідусіль, зробити commit і оновити сервер через `git pull` та `docker compose up -d --build`. Сам бот доступний у Telegram звідусіль незалежно від вашого комп'ютера.

Перший запуск планується на **Oracle Cloud Always Free Ampere A1**: одна Ubuntu ARM64 VM із 2 OCPU і 4 ГБ RAM у межах безкоштовного ліміту 2 OCPU/12 ГБ. Oracle може не мати вільної місткості у вибраному Home Region і може вилучати малоактивні безкоштовні VM; розмір 4 ГБ не гарантує, що інстанс не буде визнано неактивним. Штучне навантаження для обходу цієї політики не використовується. [Oracle Always Free](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm)

Якщо Oracle не дасть створити VM або робота бота перерветься, запасний платний варіант — **netcup VPS nano G11.5s** (2 vCore, 2 ГБ RAM, 60 ГБ SSD, приблизно €3,81/міс для Португалії, оплата за 6 місяців). На 2 ГБ швидкість голосу треба виміряти окремо. [Тариф netcup](https://www.netcup.com/en/server/vps/vps-nano-g11.5s-iv-6m-nue), [порівняння хостингів](docs/hosting-research.md)

## Локальна розробка та Git

```bash
git clone YOUR_PRIVATE_GITHUB_REPOSITORY_URL
cd family-shopping-bot
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

Рекомендований процес: окрема гілка для змін → тест → commit → pull request → merge в `main` → `git pull` на сервері → перезапуск Compose. Секрети, база й фото не додаються до Git. GitHub Actions запускає тести при push і pull request.

## Розгортання на Linux VM

Для першого створення Oracle VM запустіть локальний [майстер Oracle](scripts/oracle-vm-wizard.sh): `bash scripts/oracle-vm-wizard.sh`. Він проведе через акаунт, SSH, Always Free ARM VM, read-only deploy key GitHub і BotFather; публічну IP-адресу збереже в `.oracle-setup.env`, секрети — у локальному `.env`. Обидва файли виключені з Git. Коли майстер завершиться, передайте помічнику лише публічну IP-адресу для налаштування сервера.

Потрібні Docker Engine із Compose plugin, Git і приватний доступ до репозиторію. Для Oracle оберіть Ubuntu 24.04 ARM64; для netcup — Ubuntu 24.04 x86_64. Доступ до приватного GitHub-репозиторію на сервері налаштуйте через окремий read-only deploy key або GitHub CLI; персональний токен не зберігайте в коді.

1. У [@BotFather](https://t.me/BotFather) створіть бота командою `/newbot`. Збережіть HTTP API token. Не надсилайте токен у чат і не додавайте в Git.
2. Клонуйте репозиторій на сервер і відкрийте папку:

   ```bash
   git clone YOUR_PRIVATE_GITHUB_REPOSITORY_URL family-shopping-bot
   cd family-shopping-bot
   ```

3. Створіть `.env` і приватний код доступу для двох людей:

   ```bash
   cp .env.example .env
   python3 -c 'import secrets; print(secrets.token_urlsafe(24))'
   nano .env
   chmod 600 .env
   ```

   Запишіть токен у `TELEGRAM_BOT_TOKEN`, а згенерований код у `SHOPPING_INVITE_CODE`.

4. Створіть папку даних із правами контейнера та запустіть бота:

   ```bash
   mkdir -p data
   sudo chown -R 10001:10001 data
   docker compose up -d --build
   docker compose logs --tail=50 bot
   ```

   Перший build завантажує та компілює `whisper.cpp` версії `v1.9.4` і багатомовну модель `small`, тому може тривати кілька хвилин. Код не відкриває мережевий порт. Якщо голос працює повільно, можна перевірити меншу багатомовну модель `tiny`; це потребує окремого build і зміни шляху моделі.

5. Кожен із вас відкриває особистий чат із ботом і один раз надсилає `/join ВАШ_КОД`. Приєднатися можуть лише перші два Telegram-акаунти з правильним кодом.
6. Перевірте: додайте товар в одному чаті, відкрийте «Список» у другому, відмітьте покупку й перевірте сповіщення.

Оновлення після merge в `main`:

```bash
git pull --ff-only origin main
docker compose up -d --build
```

Перед оновленням робіть резервну копію; Compose зберігає `./data` між перезапусками. На сервері необхідно налаштувати звичайні оновлення ОС та захист SSH.

## Користування

- Надішліть `молоко, яйця, хліб @Lidl`, перевірте чернетку й натисніть **Додати**.
- Надішліть фото упаковки з підписом `молоко` — воно прив'яжеться до товару, а товар стане активним у списку.
- Надішліть коротке голосове «сьогодні треба купити яйця, молоко і хліб». Бот покаже транскрипт та список для підтвердження. Перед додаванням натисніть «Виправити», щоб змінити назву, нотатку чи категорію або прибрати товар. Текст і голос використовують однакову чернетку.
- Відкрийте «🛒 Список». Натисніть ✅ біля купленого; 📷 відкриває упаковку.
- У **Каталозі** можна знову додати товар або додати, змінити чи прибрати нотатку (до 200 символів). Після кнопки «Нотатка» можна надіслати текст або голосове: розпізнана українська фраза зберігається повністю як нотатка, без створення товарів.

## Резервні копії

SQLite та фото лежать у `./data`. Архів потрібно копіювати **за межі VM** — GitHub для приватних фото й бази не використовується.

```bash
mkdir -p backups
sudo chown -R 10001:10001 backups
docker compose run --rm -v "$(pwd)/backups:/backups" bot \
  python -m shopping_bot.backup --data-dir /data --output-dir /backups
```

Команда робить узгоджений знімок SQLite навіть під час роботи бота. Після копіювання архіву на інший носій його можна відновити: зупинити бота, розпакувати `shopping.sqlite3` і `photos/` у `./data`, запустити бота. Фото в Telegram зазвичай лишаються доступними за `file_id`, але локальні копії входять до резервного архіву.

### Категорії товарів

Текстові й голосові назви автоматично отримують категорію зі словника українських та португальських слів, без AI та зовнішніх запитів. Чернетка показує категорію перед підтвердженням. Єдиний список групується за категоріями. У каталозі відкрийте товар → «Змінити категорію», щоб виправити результат; вибір зберігається для повторних покупок. Незнайомі або неоднозначні назви залишаються в «Інше». Це початковий словник, не повний каталог Mercadona. При першому запуску після оновлення категорії додаються до наявних товарів автоматично, зі збереженням фото та історії. Старі явно обрані Lidl/Auchan переносяться в нотатки; автоматичний Mercadona не створює нотатку.

### Навігація в боті

Натисніть назву товару в списку, щоб відкрити картку; «Куплено» відмічає покупку. Картки та каталог оновлюють те саме повідомлення, а кнопка «До списку» повертає назад. Після «Додати нотатку» надішліть текст або голосове; «Скасувати» чи перехід у головне меню виходить із цього режиму. Остання покупка показується в одному повідомленні з кнопкою скасування. Для оновлення постійної клавіатури після оновлення надішліть `/start`.

## Telegram Mini App

Кнопка «Покупки» в меню бота відкриває вебінтерфейс усередині Telegram. Після `/start` є також повідомлення з кнопкою «Відкрити застосунок»; команда `/app` показує її знову. Mini App запускається через меню або inline-кнопку, щоб Telegram передав перевірювану авторизацію. Екрани: спільний список за категоріями, каталог із пошуком та повторним додаванням, історія; картка показує фото й дозволяє редагувати нотатку та категорію. Додавання товарів має попередній перегляд; покупку можна скасувати протягом показу повідомлення з кнопкою. Дані другого учасника оновлюються кожні 5 секунд, поки застосунок відкритий. Голос і завантаження фото поки залишаються в чаті бота.

Застосунок використовує наявну SQLite й фото. Python HTTP-сервер запускається поряд із ботом у тому самому контейнері; порт 8080 відкрито тільки на localhost Mac. Немає npm-збірки чи платного API. Перевірка підпису `Telegram.WebApp.initData` і членства в сім’ї потрібна для кожного API-запиту й фото. Сесія чинна 1 годину; після цього закрийте Mini App і відкрийте знову. Авторизація передається заголовком, не через URL; токен бота залишається на сервері. [Протокол Telegram](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app)

### Тимчасовий HTTPS на ноуті

```bash
docker compose --profile miniapp up -d --build
python3 scripts/refresh-miniapp-url.py
```

Скрипт бере поточну адресу Cloudflare Quick Tunnel, записує `SHOPPING_WEB_URL` у локальний `.env` та перезапускає бота для оновлення кнопки. Тунель без акаунта використовує випадкову адресу: після перезапуску тунелю вона може змінитися, тоді повторіть скрипт. Для постійної адреси потрібен named tunnel із доменом або HTTPS на сервері. Quick Tunnel призначений для тестування й не має гарантії доступності. Mac та Docker мають працювати. Cloudflare передає HTTP-трафік до ноутбука; API не відкриває сімейні дані без перевіреної сесії. [Cloudflare Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)

Для перегляду дизайну без сімейних даних відкрийте `http://localhost:8080/?demo=1`. Це окремі демонстраційні дані лише в браузері, без доступу до бази. Бойовий API не має demo-авторизації.

Перевірка Mini App: звичайна команда unittest включає API, підписи авторизації, приватність фото та одночасні покупки. Для перевірки мобільного UI на ізольованій тестовій базі встановіть Playwright у середовище розробки (`pip install playwright`, `playwright install chromium`) й запустіть `python tests/miniapp_browser_check.py`. Бойові сімейні дані цей тест не змінює.

### Швидкість і реакція на покупки

Галочка одразу показує стан покупки, промальовується та плавно прибирає рядок; якщо запит не підтверджено, товар повертається й список звіряється із сервером. Налаштування зменшення руху на телефоні вимикає анімації. Сповіщення Telegram та оновлення повідомлень виконуються фоновим послідовним виконавцем після запису в SQLite й не затримують API-відповідь. JS/CSS мають хеш у URL і кешуються між відкриттями, а фото завантажуються біля видимої частини списку. Тест зі штучною затримкою Telegram 1 секунду відтворив стару відповідь ~1014 мс; після зміни локальна відповідь становила ~3 мс. Це вимірювання локального API на тестовій базі, не мережі чи всього застосунку.

### Візуальний стиль

Onest для заголовків і назв товарів, Manrope для тексту й форм; обидва шрифти містять українські літери, локально збережені у WOFF2 разом із OFL-ліцензіями. Палітра графітова й молочно-біла з фіолетовими діями; темна тема використовує лавандовий акцент. Навігація має узгоджені SVG-іконки, форми відкриваються знизу, короткі анімації поважають reduced-motion. Джерела та рішення — у [нотатці про дизайн](docs/miniapp-design.md).

Головна клавіатура чату: «Покупки», «Додати голосом», «Список у чаті». Для її оновлення надішліть `/start`. У порожньому списку Mini App кнопка «Купити знову» відкриває каталог зі збереженими товарами.

Голос використовує локальну модель `small`, мова українська. Словник точних синонімів об’єднує «картошка» / «картопля», «фріха» / «картопля фрі» та поширені форми назв у нових списках. Картопля та фрі, бренди й уточнення залишаються окремими товарами. Наявні картки не видаляються; повторне додавання використовує наявну активну картку або найстарішу збережену. Невідомі назви не виправляються приблизним зіставленням.
